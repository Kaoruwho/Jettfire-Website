JETTFIRE WEBSITE - SEPARATED FILES

Open index.html in a browser or use the VS Code Live Server extension.

Files:
- index.html: page content and structure
- css/style.css: all styling and responsive rules
- js/script.js: mobile menu, gallery filters, and quotation form behavior
- images/: put local images here; portfolio/ is for project photos

All existing sample images still use external Unsplash URLs, so they require internet until you replace them. To use local images, change the src attribute in index.html, e.g. src="images/hero.jpg".

The quotation form opens a pre-filled email; it is not connected to a server. Verify company contact details before publishing.
